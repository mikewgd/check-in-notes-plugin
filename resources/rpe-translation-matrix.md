# RPE Translation Matrix

A quick lookup from the RPE logged for a set to the reps left in reserve, what the set tends to feel like, and how it's usually used.

| RPE | Reps left (RIR) | What it feels like | Typical use |
|---|---|---|---|
| 10 | 0 | Failure. Another rep wasn't possible without breaking form; the last rep crawled. | Final set of an exercise or a deliberate top set. Avoid on every set. |
| 9.5 | 0–1 | Almost failure. A full rep was unlikely; maybe a partial one. | Hard last sets. |
| 9 | 1 | One clean rep left. The last rep was clearly slower. | Top working sets. |
| 8.5 | 1–2 | One rep in the tank, maybe two. | Common for working sets in hypertrophy rep ranges. |
| 8 | 2 | Two more good reps were available; bar speed still crisp. | Baseline for main work. |
| 7.5 | 2–3 | Moderate effort; speed slows a little late in the set. | Accessory work, or when trying a new exercise or rep range. |
| 7 | 3 | Comfortable. Three more reps were available. | If the first set lands here, the weight can probably go up. |
| 6 | 4+ | Light. The weight moved easily. | Warm-up sets; not counted as working volume. |
| < 6 | 5+ | Very light. | Usually left unrated. |

## Two trend patterns worth recognizing

- **RPE rising across sets at the same weight** (for example 8 → 8.5 → 9.5). The same load is costing more each set. Rest time, the exercise's position in the workout, and day-to-day readiness can all play a part.
- **RPE falling for the same weight and reps from one week to the next** (for example 9 → 8). The same work felt easier than before.

Both are observations about the numbers. Which explanation fits is a call for the trainer.
