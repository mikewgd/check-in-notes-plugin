# Analyzing Workout Performance with RPE

Patterns in a week of logged sets that are worth surfacing. In each case, state what the numbers did and leave interpretation to the trainer.

1. **RPE movement across sets at the same weight.** Note rises or drops, with the actual values (for example 8.5 → 9.5 over two sets).
2. **Weight changes alongside RPE.** Weight up while RPE held, weight dropped mid-exercise after a hard first set, or the same weight and reps feeling different from last time.
3. **Sets at RPE 9.5–10.** These are near-failure efforts. Note them factually, especially when they recur across several exercises or show up on early sets of an exercise.
4. **Position in the session.** An exercise done late in a workout can run at a higher RPE than the same exercise done early. Compare like with like when the data allows.
5. **Notes next to the numbers.** Form or control comments, subbed machines or equipment, a crowded gym, skipped warm-ups or exercises, and time pressure give context for why a set landed where it did. Quote them as reported rather than inferring causes.
6. **Outside conditions.** Sleep, heat, time off, or fatigue that the lifter mentions can be passed along as stated, but shouldn't be assumed when the notes don't mention them.

## Reporting guidance

- Report what happened in plain terms. Don't label a pattern as fatigue, overtraining, progress, or a programming problem.
- Pick the few most notable data points across the week instead of listing every set.
- RPE is a self-rating, so treat a single set as a rough signal and repeated patterns as stronger ones.
